# Admin API

Endpoints:

- **GET** /bff/admin/products — List products (admin)
- **POST** /bff/admin/products — Create product (admin)
- **GET** /bff/admin/products/presign — Get product image presign URL (admin)
- **PUT** /bff/admin/products/{id} — Update product (admin)
- **DELETE** /bff/admin/products/{id} — Delete product (admin)
- **POST** /bff/admin/products/{id}/images/presign — Get existing product image presign URL (admin)
- **GET** /bff/admin/categories — List categories (admin)
- **POST** /bff/admin/categories — Create category (admin)
- **PUT** /bff/admin/categories/{id} — Update category (admin)
- **DELETE** /bff/admin/categories/{id} — Delete category (admin)
- **POST** /bff/admin/categories/bulk — Bulk create categories (admin)
- **GET** /bff/admin/promotions — List coupons (admin)
- **POST** /bff/admin/promotions — Create coupon (admin)
- **DELETE** /bff/admin/promotions/{code} — Deactivate coupon (admin)
- **GET** /bff/admin/users — List all users (admin)
- **POST** /bff/admin/users — Create user (admin)
- **PUT** /bff/admin/users/{id}/role — Update user role (admin)
- **DELETE** /bff/admin/users/{id} — Delete user (admin)
- **GET** /bff/admin/orders — List orders (admin)
- **GET** /bff/admin/orders/{id} — Get order by id (admin)
- **PUT** /bff/admin/orders/{id}/status — Update order status (admin)
- **GET** /bff/admin/inventory — List all inventory items (admin)
- **PUT** /bff/admin/inventory/{product_id} — Update inventory (admin)
- **GET** /bff/admin/coupons — List coupons (admin)
- **POST** /bff/admin/coupons — Create coupon (admin)
- **PUT** /bff/admin/coupons/{id} — Update coupon (admin)
- **DELETE** /bff/admin/coupons/{id} — Delete coupon (admin)
- **GET** /bff/admin/notifications — List notifications (admin)
- **GET** /bff/admin/notifications/log — Notification logs (admin)
- **GET** /bff/admin/reports/sales — Sales analytics report (admin)
- **GET** /bff/admin/reports/users — Users analytics report (admin)
- **GET** /bff/admin/reports/inventory — Inventory analytics report (admin)
